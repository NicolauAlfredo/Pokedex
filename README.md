# Pokédex

A JavaScript project built with HTML, CSS and Vanilla JavaScript using the Fetch API.

The goal of this project is to practice API consumption, DOM manipulation, asynchronous JavaScript, modular architecture and clean Git workflow.

## Tech Stack

- HTML
- CSS
- JavaScript
- Fetch API
- PokeAPI
